# COOKSTA 场景参考

## 选项与默认值

| 维度 | 可选值 | 默认值 |
| --- | --- | --- |
| 场景 | 班乔主店、分店、海上 | 班乔主店 |
| 时段 | 白天、傍晚、夜晚 | 白天 |
| 天气 | 晴、雨、雾 | 晴 |

「班乔」「主店」都指班乔主店。可将「黄昏」「晚上」「晴天」「下雨」「有雾」等明确表达归一为对应选项。只填某一项时，其余项独立取默认值。若用户要求修改已生成的图，沿用该图原有组合，仅更新明确要求改变的项。

## 选图与生成

1. 用户明确指定参考截图时，以该图为底图。用户同时指定的场景、时段或天气若与图中画面冲突，先取得满足要求的截图。
2. 没有指定单张图时，在用户指定的参考目录和 Skill 可用的本地参考目录中查找三项全匹配的图。默认使用 [动态替换流程](feed-compositing.md)，背景的时段与天气来自原图。
3. 缺少精确匹配时，请用户提供目标截图。用户明确接受近似背景时，优先使用同场景、同时段的底图，之后考虑同天气的同场景底图。只调整目标时段或天气。例如「海上＋傍晚＋雨」可用 `海上-傍晚-晴.JPG` 保留暮色并补雨景。
4. 用户接受近似背景且没有同场景参考图时，可按下方环境描述生成完整画面。保留居中的深色手机、挂件、粉色 COOKSTA 顶栏、料理图和白色动态区。简要告知用户背景是生成的。

手机中的新料理始终来自实拍照片。近似生成时，晴雨、雾和时间光线只施加在手机外的环境中，保持插图与动态文字清晰。

## 无参考图时的环境描述

- **班乔主店**：木质海边寿司吧台、草顶、紫色布幔、右侧厨房和粉色花枝。
- **分店**：开放式木质寿司店、青绿布幔、白色吊扇、吊灯，窗外可见海岸建筑。
- **海上**：开阔海面、小型潜水船、远处岩壁和岛上建筑。背景使用室外海景。
- **白天 / 傍晚 / 夜晚**：分别使用自然日光、低角度暖色暮光、深蓝环境光与局部暖灯。画面光源与时段一致。
- **晴 / 雨 / 雾**：分别表现清晰远景、室外雨丝与湿润水面、远景低对比度和层叠雾气。雨丝和雾留在室外背景，手机保持清楚。
